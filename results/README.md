# Results data dictionary

Everything here is written by `python latent.py` (defaults: `--min-mp 300 --k auto --runs 10 --seed 0`).
This file describes what each field is and how it is computed.

## Conventions used everywhere

- **pid**: Basketball-Reference player id, e.g. `doncilu01`. Player page: `https://www.basketball-reference.com/players/{pid[0]}/{pid}.html`.
- **Team codes**: Basketball-Reference abbreviations (`ATL`, `BRK`, `CHO`, `PHO`, ...).
- **k**: number of latent axes (8 by default; see `manifest.k`). Any list of length k is indexed by axis: index 0 = axis 1.
- **z**: a player's position on the latent axes. Prior is standard normal, so values are roughly in -3..3 and have no units.
- **Axis direction**: axis 1 is signed so that `fga_0-3` has a positive loading. Every other axis is signed so its largest-magnitude loading is positive.
- **Standardised units**: each feature is transformed (logit for shares, sqrt for rates), then centred and scaled by a minutes-weighted mean and sd. Loadings and reconstruction errors use this scale.
- **p**: two-sided permutation p-value (5000 permutations unless stated).
- **p_holm**: Holm-adjusted p within its family. A family is the same test run on every axis, or the three ball-security stats.
- **ci95**: [2.5th percentile, 97.5th percentile] of a bootstrap, one value per axis in each of the two lists.
- **null**: value was not computable for that player or team (e.g. no playoff minutes).
- **Stability numbers** come from 10 refits on random 80% subsets of players. Each refit is rotated onto the main fit (Procrustes) before comparing.

## Files

| File | One row / object per | Size |
|---|---|---|
| `manifest.json` | run | tiny |
| `players.json` | player (435, those with $\geq$ 300 regular-season MP) | ~630 KB |
| `features.json` | embedded feature, and axis | ~10 KB |
| `teams.json` | team (30) | ~65 KB |
| `analysis.json` | analysis | ~25 KB |
| `defense_breakdown.json` | player, and defence score | ~390 KB |

## manifest.json

| Field | Meaning |
|---|---|
| `season` | `"2025-26"` |
| `generated_at` | local time of the run |
| `k` | number of axes used |
| `k_errors` | `{k: error}` for k = 1..12. Held-out reconstruction RMSE (standardised units), averaged over 3 random masks that each hide 10% of entries. The chosen k is the smallest within 2% of the minimum. |
| `min_mp` | minimum regular-season minutes to be embedded |
| `n_players` | number of embedded players |
| `features` | embedded feature keys, in the column order used everywhere (see `features.json`) |
| `stability_runs` | number of refits behind every stability number (0 = skipped) |
| `files` | list of JSON files written |

## features.json

`features[]`, one per embedded feature:

| Field | Meaning |
|---|---|
| `key` | feature id |
| `label` | readable name |
| `group` | `shot_diet`, `creation`, `glass_defense` or `contact` |
| `loadings` | k numbers: change in the feature (standardised units) per +1 on each axis |

Feature definitions (all regular season, per player):

| key | label | source |
|---|---|---|
| `dist` | Avg shot distance (ft) | shooting |
| `fga_0-3`, `fga_3-10`, `fga_10-16`, `fga_16-3P`, `fga_3P` | share of FGA from each distance | shooting |
| `dunk_share` | dunks / FGA | shooting |
| `corner3_share` | corner 3s / 3PA | shooting |
| `ast2`, `ast3` | % of 2P / 3P makes that were assisted | shooting |
| `AST%`, `USG%` | assist %, usage % | advanced |
| `pga` | points generated by assists per 36 min | play-by-play |
| `ORB%`, `DRB%`, `STL%`, `BLK%` | rebound / steal / block % | advanced |
| `pf100` | personal fouls per 100 possessions | per-100 |
| `charges` | offensive fouls drawn (charges taken) per 36 | play-by-play |
| `FTr` | FTA / FGA | advanced |
| `shoot_fouls_drawn` | shooting fouls drawn per 36 | play-by-play |
| `and1` | and-ones per 36 | play-by-play |
| `blkd` | own shots blocked per 36 | play-by-play |

`axes[]`, one per axis:

| Field | Meaning |
|---|---|
| `id` | 0-based axis index |
| `var_share` | share of the model's explained variance on this axis (sums to 1) |
| `name_neg`, `name_pos` | hand-written labels for the two ends. Only filled for the default configuration, otherwise null. |
| `top_pos`, `top_neg` | 4 `[feature key, loading]` pairs with the largest positive / negative loadings |
| `players_neg`, `players_pos` | 4 pids with the lowest / highest z on this axis, among players with $\geq$ 1500 MP |

## players.json

A list of 435 objects.

| Field | Meaning |
|---|---|
| `pid`, `name` | id and name |
| `team` | team code. For traded players, the team they played the most minutes for. |
| `age` | age (season listing) |
| `mp` | regular-season minutes |
| `playoff_mp` | playoff minutes (0 if none) |
| `playoff_share_change` | playoff minutes-per-game / 240 minus regular-season minutes-per-game / 240, for the playoff team. null if not on a playoff team or no playoff games. |
| `pos_listed` | Basketball-Reference listed position |
| `pos_pbp` | `{PG, SG, SF, PF, C}`: % of minutes at each position (play-by-play) |
| `pos_num_pbp` | pos_pbp averaged on a 1 (PG) ... 5 (C) scale |
| `pos_num_latent` | position predicted from z alone (leave-one-out linear readout), clipped to 1..5 |
| `pos_gap` | `pos_num_latent - pos_num_pbp` |
| `pos_primary_recovered` | position with the largest average pos_pbp among the player's 10 nearest neighbours in z |
| `z` | k axis coordinates (posterior mean) |
| `z_sd` | k posterior standard deviations, from the player's own sample sizes |
| `columns_xy` | `[listed position index 0..4 (2 if unknown), random jitter in -0.4..0.4]`, a fixed layout helper |
| `awards.votes` | `{award: vote rank}` for MVP, DPOY, ROY, MIP, 6MOY, CPOY (1 = won) |
| `awards.all_star` | true / false |
| `awards.all_nba`, `awards.all_def`, `awards.all_rookie` | team number (1, 2, 3) or null |
| `def_score` | z projected on (mean z of All-Defensive players − mean z of everyone) |
| `def_rank` | rank of def_score among the 435 (1 = highest) |
| `def_score_pc`, `def_rank_pc` | same, after removing the direction in z that best predicts `pos_num_pbp` |
| `def_pct_in_position` | percentile (0–100) of def_score among players with the same primary play-by-play position |
| `twins` | 5 nearest players in z (Euclidean), nearest first |
| `impact.on_court` | on-court net rating per 100 possessions (play-by-play) |
| `impact.on_off` | on-court minus off-court net rating per 100 possessions |
| `impact.on_off_expected_from_style` | on_off predicted from z (leave-one-out linear readout) |
| `impact.beyond_style_raw` | `on_off - on_off_expected_from_style` |
| `impact.beyond_style` | beyond_style_raw shrunk toward the mean by minutes (see `analysis.impact.shrinkage`) |
| `impact.shrink` | shrinkage factor used (0 = fully shrunk, 1 = unshrunk) |
| `playoff_style` | only for the 102 players with $\geq$ 150 playoff MP (key absent otherwise) |
| `playoff_style.z`, `playoff_style.z_sd` | playoff placement, using only the 8 features the playoff tables have (`analysis.playoff_style.features_used`) |
| `playoff_style.regular_z_same_features` | regular-season placement from the same 8 features, with sample sizes scaled to the player's playoff minutes. Compare `z` with this, not with the top-level `z`. |
| `stability.z_sd` | k sds of z across refits |
| `stability.twin_freq` | share of refits where the nearest twin is still among the 5 nearest |
| `stability.twin_top1_freq` | share of refits where the nearest twin is still the nearest |
| `stability.twin_stable` | `twin_top1_freq >= 0.6` |
| `stability.misfit_freq` | share of refits where the player is in the top-12 largest \|pos_gap\| (players $\geq$ 1000 MP) |

## teams.json

A list of 30 objects.

| Field | Meaning |
|---|---|
| `team`, `name`, `conference`, `division` | identifiers |
| `W`, `L`, `NRtg`, `SRS` | regular season |
| `centroid` | k numbers: regular-season minutes-weighted mean z of the team's embedded players |
| `roster[]` | `{pid, share}`: share of the team's embedded-player regular-season minutes |

Playoff teams only (key absent for the other 14):

| Field | Meaning |
|---|---|
| `playoff_centroid` | playoff-minutes-weighted mean of the players' regular-season z |
| `playoff_shift.who_plays` | `playoff_centroid - centroid` |
| `playoff_shift.how_they_play` | playoff-minutes-weighted mean of (`playoff_style.z - playoff_style.regular_z_same_features`). Players without a playoff placement count as 0. |
| `playoff_shift.total` | who_plays + how_they_play |
| `playoff_shift.coverage` | share of the team's playoff minutes from players with a playoff placement |
| `playoff_shift.n_playoff_players` | embedded players who played for the team in the playoffs |
| `playoff_shift.who_plays_ci95`, `how_they_play_ci95`, `total_ci95` | bootstrap over the team's playoff players (1000 draws, weights renormalised each draw). Two lists: lower bounds, upper bounds. |
| `playoff_shift.how_they_play_not_sample_matched` | how_they_play where the regular-season placement uses full regular-season sample sizes |
| `playoff_shift.how_they_play_without_usg_ast` | how_they_play with USG% and AST% left out of both placements |
| `playoff_results.series_won`, `series_played` | from `playoff-series.csv` |
| `playoff_results.games_won`, `games_lost` | summed over series |
| `playoff_results.NRtg`, `ORtg`, `DRtg`, `Pace` | playoff team advanced stats |

### misfits[]

The 12 players ($\geq$ 1000 MP) most often in the largest-\|pos_gap\| set across refits (kept if $\geq$ 50% of refits).

| Field | Meaning |
|---|---|

| `freq` | share of refits in the misfit set |
| `gap_sd` | sd of pos_gap across refits |
| `stable` | freq $\geq$ 0.6 |

## defense_breakdown.json

Each defence score is linear in the player's standardised features. It splits exactly into one piece per feature plus a constant: `score = offset + sum(pieces)`.

| Field | Meaning |
|---|---|
| `feature_order` | feature keys; every list of pieces follows this order |
| `scores.{raw, position_controlled, position_and_creation_controlled}.offset` | the constant |
| `scores.*.direction_z` | k numbers: the score's direction in z |
| `scores.*.feature_direction` | `{feature: value}`: change in the feature (standardised units) per +1 of score direction (loadings · direction_z) |
| `scores.*.max_abs_residual` | largest \|offset + sum(pieces) − score\| over all players (should be ~0) |
| `players.{pid}.{raw, position_controlled, position_and_creation_controlled}` | 23 pieces per player |

`raw` corresponds to `players[].def_score`, and `position_controlled` to `players[].def_score_pc`. `position_and_creation_controlled` corresponds to `analysis.all_defense.position_and_creation_controlled`.
